# TANTARA

AI-powered legal workspace for arbitration law. *(MVP)*

## Overview
TANTARA helps arbitration practitioners research, organize, and draft
case work in one place. This repo holds the MVP, built by a 5-person
team over a 1-month phased plan.

## Problem
- Arbitration research and drafting are time-consuming and scattered
  across tools.
- provides a positive slop in the scalability for lawyers with a ready virtual assistant that will keep track of the cases under belt.
- The user will better be able to manage their resources as well as take up scalable business opportunities

## MVP Features
- Landing page with navigation to app screens
- Login / authentication
- Core workspace screens (designed in Google Stitch)
- features available: case based ai supported drafting, upload and bundling of documents for cases, summary of individual cases and timeline, along with a tabular summary of user cases
